# Vendored: Taste Skill

This folder is a verbatim copy of the `skills/taste-skill` directory from
[leonxlnx/taste-skill](https://github.com/leonxlnx/taste-skill), by Leonxlnx,
used under the MIT License (see `LICENSE` in this folder).

- Source commit: `f6b76575f949707b4e3c37cd86cb44b0b98643e8` (skill version 2.5.1)
- Installed as `design-taste-frontend`, the skill's own name, so the Stop-hook
  path in `SKILL.md` (`.claude/skills/design-taste-frontend/scripts/gate.mjs`) resolves.
- Image and icon credits ship with the assets (`credits.json`, `icons-credits.json`).

To update, replace this folder with a newer copy of `skills/taste-skill` and
bump the commit above. Requires Node 22+ and Chrome/Chromium for its checker.

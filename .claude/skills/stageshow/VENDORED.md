# Vendored: Stageshow

This folder is a verbatim copy of the `stageshow` directory from
[benjitaylor/skills](https://github.com/benjitaylor/skills), by Benji Taylor,
used under the MIT License (see `LICENSE` in this folder). It is what
`npx skills add benjitaylor/skills --skill stageshow` installs.

- Source commit: `299140fafd08df55a9c234e610c3f64af3f45531` (skill version 1.1.1)
- Installed as `stageshow`, the skill's own name.
- Third-party notices ship with the skill: `NOTICE.md`, the brand-icon licenses
  and `SOURCES.md` in `kit/brands/`, and the photo credits in
  `examples/wikipedia/PHOTOS.md`. App icons in `assets/app-icons.ts` and brand
  marks belong to their owners and are not covered by the MIT license.

To update, replace this folder with a newer copy of `stageshow` and bump the
commit above. The playground and filming tools need Node 20.19+ and a local
Chrome/Chromium; run `npm install` inside this folder to use them.
